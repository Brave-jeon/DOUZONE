# SalesPilot GitHub 연동 공유 로그인

## 준비 상태와 주의사항
- GitHub Pages는 화면 파일만 제공하며 회원 서버를 실행하지 못합니다.
- 이 구성은 GitHub의 배포 브랜치를 Render HTTPS 실행 서버에 연결합니다. 영구 SQLite 디스크를 사용합니다.
- 배포 파일을 GitHub에 올리는 것과 실제 서버를 생성하는 것은 별개입니다. Render 로그인·GitHub 저장소 연결·유료 서버와 디스크 비용 확인이 필요합니다.
- 기존 PC 회원 DB, 비밀번호 원문, 로그인 세션, 보안 키를 GitHub에 올리지 않습니다.
- 실제 서버 URL을 확정하고 기존 계정 이전을 완료하기 전까지 GitHub Pages와 기존 PC 실행본은 변경하지 않습니다.

## 1. GitHub에서 실행 서버 연결
1. Render에 본인 계정으로 로그인합니다.
2. 새 Blueprint를 만들고 GitHub 저장소 `Brave-jeon/DOUZONE`과 `shared-login-20261112` 브랜치를 선택합니다.
3. `render.yaml`을 확인합니다. Docker 실행 서버, 실행 플랜 `0.5c-512mb`, 싱가포르 지역, 1GB 영구 디스크를 요청하는 설정입니다. 실제 제공 플랜과 비용은 생성 화면에서 확인하고 승인하세요. 비용 승인 전에는 생성하지 않습니다.
4. `MIGRATION_KEY` 비밀 환경변수에 별도 제공된 `SalesPilot_공유서버보안키_20261112/migration-key.txt` 내용을 넣습니다. 채팅이나 GitHub 파일에 키 내용을 붙여 넣지 마세요. 기존 PC 관리자 복구 키를 대신 사용하지 않습니다.
5. 처음 배포를 실행합니다. 이후 자동 배포는 꺼져 있으므로 수동 배포로 변경을 반영합니다.
6. Render가 제공하는 HTTPS 서비스 주소를 확인합니다. 앱은 `RENDER_EXTERNAL_URL`로 자신의 주소를 인식합니다. 사용자 도메인이 필요하면 경로 없는 HTTPS 원점 주소를 `PUBLIC_URL`에 지정해야 합니다.

## 2. 기존 PC 계정·자료 이전
1. Render 새 서버가 준비되면 이 폴더의 `계정이전_실행.cmd`를 실행합니다.
2. 서비스의 HTTPS 주소를 입력합니다. 새 서버가 맞는지 확인하고 전송 질문에 `y`로 동의합니다.
3. 도구는 PC의 `.oneai/workspace/salespilot-server-data/members.sqlite`를 읽기 전용으로 조회합니다. 기본 파일 위치가 다르면 도구 실행 인자로 원본 파일 경로를 지정할 수 있습니다.
4. 회원, 회원별 문서, 설정, 메타데이터 및 존재하는 견적 버전 관리 자료를 일회성으로 전송합니다. 기존 비밀번호 검증 해시를 보존하므로 이메일과 비밀번호를 다시 만들지 않습니다. 원본 파일은 변경하지 않고 기존 세션은 이전하지 않습니다.
5. 이전 대상 서버에 기존 데이터가 있으면 거절합니다. 전송 제한은 16MB입니다. 실패 시 대상 서버의 이전 행은 트랜잭션으로 되돌립니다.
6. 완료 후 공유 서버에서 기존 이메일·비밀번호로 로그인하고 자료가 유지되는지 확인합니다. Render 설정에서 `MIGRATION_KEY`를 제거한 뒤 재배포하세요.

## 3. GitHub 주소와 PC 바로가기 연결
- 로그인 검증이 끝나면 `app/shared-config.js`의 빈 `url`에 실제 서비스의 HTTPS 원점 주소만 입력합니다. 이 값은 공개 주소이며 비밀값이 아닙니다.
- 해당 설정과 `shared-entry.js`, 이를 로드하는 `index.html`을 GitHub Pages 배포본에 반영합니다. 현재 파일은 빈 주소여서 자동 이동하지 않습니다.
- PC에서는 같은 공유 주소를 바로가기로 사용하거나 같은 연결 파일을 PC 앱에도 반영합니다. 기존 PC 서버와 클라우드 DB를 계속 별도로 사용하면 자동 동기화되지 않습니다.
- GitHub Pages와 PC 주소의 쿠키를 공유하는 방식이 아닙니다. 두 진입점이 하나의 HTTPS 앱으로 이동하므로 같은 회원 DB와 계정을 사용하게 됩니다.

## 보안·운영
- 공유 모드는 Render의 보호된 HTTPS 프록시에서만 실행하도록 제한합니다. 컨테이너 포트를 외부에 직접 노출하지 마세요.
- 로그인을 처리할 때 동일 출처를 검증하고 `Secure`, `HttpOnly`, `SameSite=Lax` 쿠키를 발급합니다.
- 이전 키는 관리자 복구에 사용할 수 없습니다. 공유 서버의 관리자 복구는 별도의 `ADMIN_RECOVERY_KEY`를 비밀 환경변수로 설정한 경우에만 허용되며, 이전 키와 같은 값이면 서버가 실행되지 않습니다.
- 회원 DB는 영구 디스크 아래 `/var/data/salespilot`에 저장합니다. 이 디스크를 삭제하지 마세요. 운영 전에 별도 암호화 백업과 복원 절차를 정하세요.
- 요청 수 제한은 기본 서버 수준으로 적용됩니다. 실제 다중 사용자 운영 시 트래픽·용량을 확인해야 합니다.
- 테스트는 가상의 계정과 임시 DB에서 실시했습니다. 실제 인터넷 TLS 접속과 실제 계정 이전 검증은 서버 생성 뒤 수행해야 합니다.
